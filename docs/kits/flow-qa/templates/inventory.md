# User flows

One document per flow group describes how a feature works from the user's side and where its logic lives. Each document doubles as the QA plan for its group, and each scenario names the end-to-end test that proves it. The format follows the flow document standard in `docs/kits/flow-qa/flow-doc-standard.md`; the QA method is `docs/kits/flow-qa/method.md`.
